# 몫대로 (ITsMine) — 기능 명세

원본 서비스(https://dutch-pay-eight.vercel.app)를 직접 로그인해 둘러보며 정리한 화면·기능 명세입니다.
이 저장소는 같은 화면과 흐름을 새로 구현한 버전입니다.

## 1. 서비스 개요

- 이름: **몫대로** — "메뉴별 더치페이", 슬로건 "계산부터 추억까지"
- 핵심: 영수증의 **메뉴마다 먹은 사람**을 골라 정확히 나누고, 결과를 **꾸민 정산표 이미지**로 남긴다.
- 계정은 **모임장(총대)만** 필요. 참여자는 초대 링크 + 닉네임으로 가입 없이 들어온다.

## 2. 화면 목록

| 경로 | 화면 | 비고 |
| --- | --- | --- |
| `/` (비로그인) | 랜딩 + 로그인/회원가입 카드 | 영수증 스캔 데모 애니메이션, 4단계 소개(영수증 등록 · 몫 나누기 · 마음껏 꾸미기 · 정산 공유) |
| `/` (로그인) | 대시보드 | `?view=all` 전체 / 기본 진행 중 / `?view=past` 지난 정산 |
| `/archive` | 나의 정산 아카이브 | 저장한 정산표 이미지 그리드, 크게 보기, ⋯(삭제) |
| `/groups/:id` | 모임 보드 | 정산 현황, 최소 송금 안내, 영수증 내역, 정산 완료, 꾸미기 |
| `/invite/:token` | 초대 참여 | 닉네임 입력 → "가입 없이 참여하기" |

## 3. 인증

- 로그인: "아이디 또는 이메일" + 비밀번호. 실패 시 "아이디 또는 비밀번호를 확인해 주세요."
- 회원가입: 이름, 이메일, 비밀번호(8자 이상). 실패 시 "회원가입 정보를 확인해 주세요."
- 헤더: 알림 벨(뱃지), **회원 정보**(이메일 표시, 닉네임 수정 모달), **로그아웃**
- 게스트(초대 참여자): 해당 모임에만 접근하는 기기별 접속 토큰(쿠키). 총대가 "접속 링크 재발급"으로 새 링크를 만들 수 있다.

## 4. 대시보드

- 제목 "〈이름〉님의 정산", 버튼 `아카이브`, `+ 새 정산 시작`
- **지금 내 돈 흐름** 카드: "진행 중 정산 N개" 배지, `내가 받을 돈` / `내가 보낼 돈` 펼침 카드
  - 펼치면 "받을 돈 상세 N건" — 모임명, "〈상대〉에게 보낼 돈 −5,000원" / "〈상대〉에게 받을 돈"
  - 진행 중(미완료) 정산만 집계
- **정산 목록** 탭: 전체 / 진행 중 / 지난 정산(완료) + 개수
  - 항목: `혼자 정리|함께 정리` · `정산 중|정산 완료|참여 대기` · `총대` 배지, 모임명, "N명 · 영수증 N장", 오른쪽 금액("내가 보낼 돈"/"내가 받을 돈"/"최종 받을 금액")
  - 빈 상태: "아직 저장된 정산이 없어요" + `첫 정산 시작하기` / "진행 중인 정산이 없어요" + `전체 정산 보기`

## 5. 새 정산 만들기 (모달 3단계)

1. **방식**: ✍️ 혼자 정리하기(내가 참여자·영수증 전부 입력) / 🙌 함께 정리하기(링크 공유, 각자 참여)
2. **참여자**
   - 혼자: 모임 이름 + 참여자 이름 목록(`+ 참여자 추가`, × 삭제, "나는 자동으로 포함돼요")
   - 함께: 모임 이름 + 전체 인원(명 · 나 포함, 기본 4, 최소 2)
3. **확인**: 방식 / 모임 / 인원 → `모임 시작하기`

- 함께 모드 생성 직후: "모임 생성 완료" — 참여자별 **1인 1링크** 초대 URL 목록(복사/공유) + `모임 보드로 이동`
- API: `POST /api/groups {mode: SOLO|TOGETHER, name, guestNames, expectedMemberCount}`

## 6. 모임 보드

- 상단: 방식 배지, 상태(정산 진행 중/정산 완료), 총대 배지, 모임명, 멤버 아바타(첫 글자) + 인원
- 총대 메뉴 ⋯: **모임명 수정**(모달), **정산 삭제**(확인 모달: "…정산이 모든 참여자의 목록에서 사라지고 기존 초대 링크도 사용할 수 없어요.")
- 함께 모드에서 인원이 다 차기 전: 대기 화면 "모두 참여하면 정산 화면으로 자동 전환돼요", 참여 현황 N / M명, 빈 자리, `↻ 참여 현황 새로고침`
- **정산 현황**: 멤버 카드(총대 🔫, 그 외 💛) — 결제 / 내 몫 / "N원 받기"(초록) · "N원 보내기"(빨강) · "주고받을 금액 없음"
  - 카드를 누르면 아래 영수증 내역이 그 사람이 올린 영수증으로 필터됨
  - 총대에게는 게스트 카드마다 `접속 링크 재발급`
- **최소 송금 안내**(어두운 바): "철수 → 김윤재 12,000원" 칩
- **영수증 내역**: 좌측 목록(가게명, N개 메뉴, 금액), 우측 상세(날짜, 가게, "〈이름〉님이 결제", 메뉴별 단가×수량, 먹은 사람 칩, 영수증 합계), 등록자에게 `수정`/`삭제`
- 하단(총대, 진행 중): "모든 영수증을 확인했나요?" + `정산 완료` (confirm 후 잠김)
- 완료 후: 버튼이 `정산표 보기 · 꾸미기`로 바뀜, "총대가 정산을 완료했어요"

## 7. 영수증 추가/수정 (모달)

- 탭: **직접 입력** / **사진 선택**(JPG/PNG · 최대 10MB, 인식 결과는 저장 전 확인)
- 가게 이름, 결제한 사람(본인, 고정)
- 메뉴별 내역: 메뉴 이름 · 수량 · 단가, "이 메뉴를 먹은 사람" 칩(기본: 결제자), 소계, 합계
- 검증: "모든 메뉴에서 먹은 사람을 한 명 이상 선택해 주세요."
- API: `POST /api/groups/:id {action: "saveReceipt", receipt: {store_name, paid_by_member_id, items:[{menu_name, quantity, unit_price, consumer_member_ids}]}}`

## 8. 계산 규칙

- 메뉴 금액 = 단가 × 수량, 먹은 사람 수로 균등 분배. 원 단위 나머지는 앞 사람부터 1원씩.
- 멤버 잔액 = 결제 합계 − 내 몫. 양수면 받기, 음수면 보내기.
- 최소 송금: 가장 많이 보내야 하는 사람 → 가장 많이 받아야 하는 사람 순으로 그리디 매칭.

## 9. 알림

- 벨 드롭다운 "알림 N": "민수님이 참여했어요 / 〈모임〉 · 2/4명 참여", "수아님이 참여해서 모두 모였어요 🎉 / 이제 정산을 시작할 수 있어요", 시간 표시
- 빈 상태: "알림이 없어요 · 새로운 소식이 생기면 여기에 알려드릴게요"

## 10. 정산표 꾸미기 (완료 후)

- `정산표 보기 · 꾸미기` → 정산표 모달(저장된 정산표 목록 + `새 정산표 만들기`, `전체 아카이브 보기 →`)
- 꾸미기 모달: 좌측 캔버스 미리보기, 우측 도구
  - 글꼴: 기본 / 주아체 / 개구체 / 감자꽃체 / 궁서체
  - **템플릿으로 만들기**: 9가지 — 🥐 브런치, ✈️ 여행, 🎉 파티, 🪻 라벤더, 🎀 피치 다이어리, 🌼 크림 영수증, 🧈 버터 옐로, 🎟️ 흑백 티켓, 🍒 체리 레드 (테마를 바꾸면 스티커 초기화)
  - **내 사진으로 만들기**: 모임 사진을 상단 배경으로(최대 10MB)
  - 이모지 스티커(최대 12개, 12종 + 직접 입력), 문구(24자) 추가, 선택 레이어 문구/글자색 수정
  - 레이어: 드래그 이동, ↗ 손잡이로 크기·회전, × 삭제, 키보드(방향키/Shift, +/−, [ ], Delete)
  - 정산표 본문: 날짜 · 인원, 모임명, "우리 모임 정산표", 총 사용 금액, 각자의 몫, 보낼 금액 안내, 영수증 요약
  - `아카이브에 저장`(PNG 업로드 → `/api/archive/:id`), `이미지 저장`(다운로드)
